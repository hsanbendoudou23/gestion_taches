# Application Python de gestion des tâches

## Présentation
Application simple en Python permettant de gérer des tâches quotidiennes depuis la console.

## Fonctionnalités
- Ajouter une tâche avec un titre non vide.
- Afficher toutes les tâches avec leur numéro.
- Rechercher les tâches contenant un mot-clé (sans distinction entre majuscules et minuscules).
- Quitter le programme.

## Fichiers
- `main.py` : code source de l'application.
- `README.md` : présentation et méthode d'exécution.

## Exécution
1. Ouvrir le dossier du projet dans Visual Studio Code.
2. Ouvrir le fichier `main.py`.
3. Cliquer sur **Run Python File**.
4. Suivre le menu affiché dans le terminal.

## Remarque
Les tâches sont conservées uniquement en mémoire pendant l'exécution. Elles sont supprimées lorsque le programme se ferme. Aucune base de données n'est utilisée dans cette première partie.
